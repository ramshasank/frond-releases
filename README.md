# Frond

Frond is a word processor and PDF reader for the Mac that opens and saves Word documents (.docx) and PDFs. It works offline; nothing leaves your Mac unless you turn on the optional update check or choose Claude in the Writing Assistant with your own key.

This repository holds the downloads and the feedback page only. The source code is not here.

## Download

Get the newest `Frond-<version>.dmg` from [Releases](../../releases/latest). It runs on macOS 13 or later on Apple silicon Macs. Intel Macs are included but not yet tested.

## Install

1. Open the downloaded `.dmg` and drag **Frond** into **Applications**.
2. Open Frond from Applications. The first time, macOS says it can't check the app (this preview isn't notarized by Apple).
3. Open **System Settings › Privacy & Security**, scroll down and click **Open Anyway** next to the Frond message, then confirm. You only do this once.

The disk image also holds **Install Frond**, a step-by-step guide.

## This is a preview

Most Word documents look the same as in Word for Mac, but some layouts can still differ slightly. **Help › Known differences** in the app lists what is not the same yet. Keep your original files while you try it.

## Feedback

Found a problem or have an idea? [Open an issue](../../issues/new/choose). Please include the Frond version (Frond › About Frond), your macOS version, and if you can, the document (or a copy with private text removed).
